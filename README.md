# Lawren & Kam — Our Little Love Story

A small, responsive love-story page for Lawren and Kam.

## Add your photos

Open the website and choose **＋ Add photo** on each of the three memory cards. Selected photos are resized and saved in that browser, so they stay there when you revisit the page on the same device. The pictures are not uploaded to GitHub or shared with anyone.

To include photos for every visitor to the published site, add the image files to the repository and update the page to use those image paths instead. No personal photos were present in the repository when this page was created, so the cards start with gentle photo prompts.

## Preview

Open `index.html` in a browser. The page is static and needs no build step.
